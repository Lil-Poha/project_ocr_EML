### 🔌 Интерфейсы (договориться до старта)

1. **Dataset отдаёт** тензор `(1, H, W)` и текст как список номеров символов. После `collate_fn`: `(B, 1, H, W)`, тексты, длины текстов, длины картинок.
2. **Алфавит:** blank = 0, символы с 1, пробел входит, один общий файл.
3. **Все CRNN-модели** (своя и с backbone) отдают `(W', B, число_символов)` в виде log-вероятностей. Это формат CTC loss в PyTorch.
4. **TrOCR** имеет свой интерфейс (генерация текста), но метрика общая: CER считается по строкам.
5. **Checkpoint:** словарь из `state_dict`, алфавита и параметров архитектуры.
6. **Один split train / val / test** для всех моделей, иначе результаты нельзя сравнивать.

```
├── data/                          # данные, в git не попадают (кроме .gitkeep)
│   ├── raw/                       
│   │   ├── dataset/               # ВАЖНО! Сюда кладём папки с картинками: 32_1, 32_2, ...
│   │   └── teacher/               # ВАЖНО! Сюда кладём Excel-файлы с разметкой: 32_1.xlsx, 32_2.xlsx, ...
│   ├── processed/                 # labels.csv, charset.json (результат подготовки)
│   └── splits/                    # train.csv, val.csv, test.csv
│
├── ml/
│   ├── configs/                   # yaml: гиперпараметры, пути, высота картинки
│   ├── data/                      # КОД работы с данными
│   │   ├── prepare.py             # сборка labels.csv из Excel и папок
│   │   ├── charset.py             # алфавит: символ <-> номер (blank = 0)
│   │   └── dataset.py             # Dataset + collate_fn
│   ├── models/                  
│   │   ├── cnn.py                 # своя CNN (готово)
│   │   ├── rnn.py                 # BiLSTM
│   │   ├── crnn.py                # CNN + BiLSTM + линейный слой
│   │   ├── backbone.py            # готовый ResNet, адаптированный под текст
│   │   ├── crnn_pretrained.py     # CRNN с готовым backbone
│   │   └── trocr.py               # обёртка над TrOCR
│   ├── losses/
│   │   └── ctc.py                 # обёртка над CTC loss
│   ├── decoding/
│   │   └── greedy.py              # схлопнуть повторы, убрать blank
│   ├── metrics/
│   │   └── cer_wer.py             # CER и WER
│   ├── notebooks/                 # личные эксперименты (имя_эксперимент.ipynb)
│   ├── train.py                   # цикл обучения, сохранение best.pt и last.pt
│   ├── evaluate.py                # оценка на test
│   ├── trocr_eval.py              # прогон TrOCR для сравнения
│   └── export.py                  # экспорт весов (потом, ONNX)
│
├── services/                      # сайт (заглушки, потом реальная модель)
│   ├── frontend/                  # страница загрузки фото
│   ├── gateway/                   # API: принимает фото, оркестрирует
│   ├── preprocessing/             # нарезка листа на строки (позже)
│   └── recognizer/                # грузит веса, делает инференс
│
├── artifacts/                     # веса моделей (в .gitignore)
│   └── crnn_v1/

│       └── config.yaml
│
├── tests/                         # test_cnn.py: проверка форм на torch.randn

├── .gitignore                    
├── README.md                      
├── requirements.txt               # зависимости (torch ставить по pytorch.org)

```
